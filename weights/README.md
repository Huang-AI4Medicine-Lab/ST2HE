ST2HE expects pretrained pix2pix-turbo weights to live in this folder.

Included files:
- `UnCondGen.pkl` - bundled unconditional ST2HE weights
- `CondGen.pkl` - bundled conditional ST2HE weights

These files are included so the repository can run inference without a
separate weight download step.

If the weight files grow substantially, prefer Git LFS or GitHub Releases.
